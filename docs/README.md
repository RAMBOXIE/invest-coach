## 引用写法

仓库内外有两份「v3」，曾经互相撞名并导致一条铁律被引错出处：

- **上游收敛文档**（不在本仓库）一律写全路径：`research/投资教练_收敛_v3.md §2.6`
- **仓库内文档**写文件名 + 节号：`形态规格_故事驱动.md §3`

`docs/形态规格_v3_故事驱动.md` 已更名为 `形态规格_故事驱动.md`，把版本号从文件名里去掉——
版本在 git 里，不在文件名里。
