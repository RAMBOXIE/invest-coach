## 引用写法

仓库内外都可能有同名的版本号文档，引用时必须区分：

- **上游收敛文档**（不在本仓库）一律写全路径：`research/投资教练_收敛_v3.md §2.6`
- **仓库内文档**写文件名 + 节号：`形态规格_故事驱动.md §3`

**版本号不进文件名。** 版本在 git 里。
