> **宪章（owner 裁决，2026-08-22）**：「最重要的是整体考虑项目的健壮性，使得项目最终的教学是可靠的、可溯源的。数据也应当使用正确的方法来进行使用，**LLM 仅作推理和细致的教练引导、原因解释**。通过我们的软件让散户投资者有更好的投资知识和能力。」

> **登记制**：任何新的 LLM 用途必须先在本表登记（比照 SCHEMA.md 的 x_ 字段登记制），未登记即违规。四类边界的完整依据见 `知识可靠性与LLM边界.md` §4。
>
> **两条规则不是一回事，别再捆在一起**：①「事实不出自 LLM」是铁律，②「判分不经 LLM」
> 已解除永久禁令（[ADR-0001](adr/0001-判分不经-llm.md)）。过去四份文档把两者写成一条，
> 结果②被误当成不可动的，而真正要紧的①反而没被单独讨论过。

## 铁律（不随用途变化）

1. **事实不出自 LLM**：真实公司数字、准则条文、官方认定只能来自原档取数管线（EDGAR accession+行号 → facts.json → 人工核定），LLM 只解释已核定的材料。
2. **判分当前不经 LLM**（见 [ADR-0001](adr/0001-判分不经-llm.md)，**不再是永久禁区**）：
   判分=前端规则引擎，运行时 LLM 不改判、不给分、不暗示判分有误。
   owner 2026-08-26 裁决：这是**推迟**，不是禁止。维持现状的理由是离线可用 / 零延迟 /
   可复现（判分要能进勘误台账），不是「LLM 判分不可靠」。
   引入的前置条件、以及 `validate.py` R19 那把工程锁的去留，都写在该 ADR 里。
   **这里不复述结论，只引用。**
3. **LLM 起草的用户可见文本必须人工逐条签字**（x_prov.reviewed_by + 内容 hash 绑定，改动即审核过期；`--release` 未签字即阻断发布）。
4. **自审无效**：审核者不得是起草同批内容的模型/会话；机器溯源只做筛子（推进人工队列），永不签核通过。

> **#5 为什么被放弃**：散文对话要靠「前置分流 + system prompt 硬规则 + 输出侧过滤 +
> 日志抽检 + 对抗测试集」五层去堵一个会自由造句的模型。#8 换了个思路——
> **让 LLM 物理上无法造句**：它的全部输出是一个 id，答案文本永远来自冻结语料。
> 五层防御塌缩成一条白名单。这也是宪章「LLM 仅作推理」在工程上的最直接落点。
>
> `知识可靠性与LLM边界.md` §7 里针对 #5 的多层防御方案不再是现行设计，
> 保留为红队推演留档。

> **#9 和被放弃的 #5 差在哪**：两者都是运行时散文，这一点上 #9 确实回到了
> #5 的地界，所以要把差别说清楚，不能靠「这次不一样」。
>
> - **#5 要回答用户的问题**，问什么答什么，题材无边界，因此必然要靠提示词
>   去堵「别给投资建议」「别改判」——堵的是一个开放集合。
> - **#9 只回应用户自己写下的那段话**，而且材料是我们喂进去的已核定文本。
>   它的越界形态是可枚举的：编一个数字、改判、给建议。所以能用**出口检查**
>   而不是提示词来挡：数字必须在材料里出现过，否则整条丢弃。
>   这是一条确定性规则，和 #8 的 id 白名单同一类东西。
>
> **#10 为什么可以放回散文**：#5 被放弃是因为要靠提示词去堵一个开放集合。#10 的边界是可枚举的：
> 他只能说材料里有的，只能活在当年，不能荐股，不能出戏。四条都是确定性检查，不靠模型自觉。
> 而且他讨论的对象是**材料里写过的理由**（MD&A 自己给的解释、致股东信里的自述），不是编出来的动机；
> 材料里没有的，他说「这份文件里没有写」。屏上标红「LLM 扮演」，带行号的陈述仍然只来自 case.json。

> **登记这条本身是补的。** 上一轮把 review-note 实现并上线了，却没有先在本表
> 登记——而本表开头写着「未登记即违规」。补登记的同时加了门禁 E2：
> 代码里每个送进模型的 system 提示词常量都必须在本表里被点到名，
> 否则 `check_src` 报错。规则有了执行者，才不只是一句话。

## 明令禁止（A 类，永久）

生成/改写 canon 定义与出处 ｜ 生成真实公司数字或派生比率 ｜ 判分/改判/评分/评级 ｜ 前瞻信号、收益承诺、个股建议、真实主体在材料时点之后的状态 ｜ 输出材料中不存在的阈值/公式/筛选参数 ｜ 运行时检索（RAG，见可靠性文档 §1.1 裁决）

## 数据的正确用法（owner 原则的落点）

- **数字只有一条进入路径**：EDGAR/AAER 原档（evidence/ 存档 + sha256）→ 人工核定（数据核定文档，行号级）→ facts.json 机器账本 → validate R12 强制正文命中账本。LLM 在这条链上没有位置。
- **构造题豁免出处、不豁免自洽**（R13）；真实公司语境的每个数字 token 必须能指回账本条目。
- **遥测数据**：匿名、带 content_version/quiz_id/side/屏级事件（可归因），统计只产出人工复核队列（G4），永不自动改内容；「问教练」输入按敏感数据管理（保留期+打码+提示），不冒充「匿名使用数据」。
