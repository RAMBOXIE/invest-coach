# ADR-0005：真实案例用真名，不匿名、不遮挡

- 日期：2026-09-03
- 状态：已裁决

## 裁决

owner 原话：

> 一定要用真实的案例和故事，这样用户的记忆才深刻。不用隐藏这些事实案例的名字，
> 也不用遮挡，要暴露出来给用户看到，感受到。这部分很重要！

## 它改了什么

第一章原来的做法是：Sunbeam 叫「A 公司」、Dell 叫「B 公司」，从第一个案例一直匿名到
最后一关的揭晓屏才说「A 公司 = Sunbeam Corporation」。理由是「先判断、再揭晓」：
知道名字会带进后见之明。

本条把这两件事分开：**名字不是剧透，结局才是。**

- 公司名、年份、当年的当事人姓名，从第一屏起就写出来：Sunbeam 1997 年报、
  Dell 1998 财年、签署年报的 CFO 叫什么、CEO 叫什么。对中国散户来说这些名字并不自带答案，
  却能让案例长在记忆里。
- **结局仍然只在揭晓之后**：SEC 认定了什么、后来重述了多少、公司怎么样了。
  这一条有门禁守着（S9 剧透闸），不因本条而放松。
- 幕（stories）本来就是真名叙事，这次是把第一章的关卡对齐到幕的做法。

## 边界

1. 只写原档里有的名字。谁签了年报、谁是 CEO，都锚到归档原档的行号；
   原档里没出现的人不写。
2. 名字上屏与「LLM 扮演他说话」是两件事。Lehman 与 Nikola 两幕的当事人仍是
   「这份季报」「这份 10-K」——因为我们手里没有这两家决策人的陈述材料可以归档；
   把 Fuld、Callan、Milton 做成可对话的人物，要先把他们的原话（Valukas 报告里的
   访谈摘录、公开信、听证记录）归档进材料闸。这是内容增量，登记在验收自检的下一步里。
3. 复习题里的 C 公司、J 公司、K 公司是构造的练习变体，不是真实案例，不在本条范围。
   要把它们换成真实公司，每一道都要走 EDGAR 取数与账本核定，另立项。
