# ADR-0002：教练不是被扮演的身份

- 日期：2026-08-26
- 状态：已裁决

## 裁决

owner 原话：

> 用户可以选择自己的**倾向**，但**不刻板地保留某个模拟的身份**。

## 规则

1. **教练只有一个，就是「你的教练」。** 全站不出现教练的人名（`coachName()` 恒返回
   「你的教练」）。它是一个逐步了解你判断习惯的角色，不是任何人的模拟。
2. **用户选的是侧重，不是人物。** 首屏问「你希望教练先盯你哪一面？」，
   三个选项是 `TONES[].k / .d`：多讲数字与出处 / 多讲求证与流程 / 多讲我自己的偏差。
3. **扮演真人的只有一处：幕里的当事人。** `case.json` 的 `cast[0]`，
   而且他们只说原档里逐字有过的话——这是出处纪律，不是角色扮演。
4. `site.json` 的 `x_coaches` 保留：它是 `style_lines`（语气语料）的数据源。
   数据留着，名字不上屏。同 `site.json` 节点 icon 仍是 emoji 的处理原则：
   内容文件不为 UI 需求 churn。

## 保留的部分

一屏一个动作、没选完什么都不显示、教练在暗岛底部说话而不是做成一个设置面板——
这套信息架构是对的，保留（见 DESIGN.md §2）。
