## 怎么签字（D1）

两条路，同一批内容、同一套判据（判据在 `sign.py` 里定义，两处共用一份）。

**读文档**（推荐）：一次读完 18 条，每条末尾写「过」或写下问题。

```bash
python tools/render_review.py     # → build/review/签字审阅稿.md（约 108 KB）
```

**命令行**：一条一条来。

```bash
python tools/sign.py                       # 总览：谁签了 / 没签 / 过期
python tools/sign.py --show <id>           # 一条的全部待审内容 + 清单
python tools/sign.py --sign <id> --by 名字  # 记录签字
```

**签字台把「机器已经保证的」和「只有人能判断的」分开列出**，
你只需要读后者——出处命中、类型闸、时代闸、数字绑账本、原档 sha256
这些 validate 的 26 条规则已经保证了，不要重做。

只有人能判断的是 9 条：G1 五条（canon 是不是教材的话、阈值有没有标 L3、
有没有前瞻或收益承诺、归因链一句话说不说得完、表述是不是当年的口吻）
+ G2 四条（错误选项是不是真实误解、「无法判断」有没有变成惩罚、
混淆对的 key 真不真能区分、题干有没有暗示答案）。

**签字绑内容指纹。** 签完之后那份内容的任何改动都会让签字自动过期，
`validate` 会报 ERROR 要求重审——这不是麻烦，这是签字有意义的前提。

**没有 `--sign-all`**，这是刻意的：读是一条一条读的。

## D7 补的时候数出来的（原档归档）

登记的是一份没归档（SEC Form 10-K 表格）。补的时候顺手数了一遍账本里的
accession，没归档的是**六份**：

| accession | 是什么 | 谁在引它 |
|---|---|---|
| AAER-1393 | SEC 对 Sunbeam 的认定书 | 「至少 6,200 万来自会计舞弊」 |
| LR-21599 | SEC 与 Dell 的和解释文 | 终局披露 |
| LBHI-2007-10K 等三条 | 雷曼 2007 年报 + 两份 2008 季报 | 「现金还在，公司没了」那三个数字 |

**S7（引文锚定）在找不到原档时只报一句 WARN 然后放行**，所以这些引文的逐字性
从来没有任何东西查过——包括这个产品里最硬的那句「SEC 认定」。
这就是本仓反复栽的那种失败：检查还在，但它什么也没查。

顺带查出来的：

- 雷曼三条事实的 accession 是占位符（`LBHI-2007-10K`），不是真申报号；
  行锚写的是 `p.86` 这种纸质页码，对不上归档文件。都换成了真申报号 + 行号。
- 核对 10-K 里的 7,286 时发现另一处同样的数字是 non-interest expense，
  不是现金——不核对原档就发现不了这种。
- 幕的内容指纹不含 `interrogation`：签完字之后把整屏证词换掉，签字仍然有效。

补法：七份原档入 `evidence/` + sha256；S7 加 PDF 页锚、按可见字数自适应扩窗、
日期整体核对；新增 S7b（每条证词必须有锚）、S7c（译文必须带原文，机器逐字核）、
R28（账本里每个 accession 都要有归档，例外写理由）。

## 实验区为什么曾经挂着（D6 的真实原因）

登记时写的是「需律师意见」。真正开工之后查出来，主要风险不是法律，是**真实性**。

管线第一轮跑出四卷，四卷都有监管问询函，看着很硬。但日期是：

| 公司 | 问询函 | 数据期 | 间隔 |
|---|---|---|---|
| HILL | 2016-09 | 2021-12 | 5 年 |
| ILLUMINA | 2011-04 | 2025-12 | 14 年 |
| HMS | 2014-05 | 2020-12 | 6 年 |
| HP | 2010-01 | 2025-10 | 15 年 |

而卡上写着「**监管刚**就相关科目向它发过问询函」。一封 2010 年给 HP 的例行问询函
和它今天的应收比率毫无关系，把两者摆在一起就是在请读者去连一条不存在的线。
**连当时已经上线的那一卷（HILL）都在这么说。**

免责声明修不了这个。声明能说「我们不主张它违规」，但修不了一次错误的并置。
一个教人「不要过度解读证据」的产品，自己不能这么干。

处置：加确定性判据 `letter_is_current()`（问询函申报日与报告期末相差 ≤18 个月），
超窗就**不带这封信**，那一卷退化为 `shape_only`，声明也换成对得上的那一段
（明写「没有任何监管机构就此提出过问询」）。四卷跑完，没有一卷有同期问询函。

**顺带查出管线自己踩了产品教的坑。** 1.8 倍的比值规则没有绝对幅度下限：
HP 是收入 +3.2% / 应收 +11.2%，比值 3.5 倍被判为异常信号——可 8 个百分点的
差距建立在两个都很小的增速上，那是噪音。这正是 `small-base`（基数过小时增速失真）
要教的东西。补了两个下限（差距 ≥10 个百分点、应收增速本身 ≥15%），HP 被正确剔除。
