## 0. 一句话体验

> **跟着你选的教练，在历史实战里一天几分钟地做决策——教练盯的不是你对没对，而是你的判断习惯。**

## 1. 支柱一：教练系统（多学派人格）

**是什么**：开局选一位主教练，全程陪练。教练是**学派原型**，不是真人（v3 §3.3.3 / v2 继承：不用真人名——在世投资人的姓名权与公开权是法律口，不碰）：

| 教练原型 | 学派底色 | 口头禅气质 | 在第一章里盯什么 |
|---|---|---|---|
| 价值派老先生 | 格雷厄姆传统：数字与出处 | 「教科书怎么说？」 | 证据够不够、原文读没读 |
| 风控派操盘手 | 先想亏多少：怀疑与求证 | 「先假设它有问题」 | 求证链走没走完、敢不敢说无法判断 |
| 行为金融学者 | 盯你这个人：偏差与纪律 | 「你上次也是这么错的」 | 过度自信、结果偏差、档案里的重复错误 |

**怎么工作**：
- **学派有真出处，人格不用真名**（裁决 2026-08-22）：每位教练的介绍卡标注「思想出处」——价值派：格雷厄姆《证券分析》《聪明的投资者》；风控派：做空研究与法务会计传统（Schilit《财务诡计》、SEC 执法档案）；行为金融学者：卡尼曼—特沃斯基一系（前景理论、《思考，快与慢》）。学习者随时能看到思路从哪里来；真名真书只用于出处引用，不用于人格命名。
- **判分永远是规则的、唯一的**；教练不改对错，只改**视角与语气**——同一道题，价值派说「你没查出处」，风控派说「你没走完求证」，行为派说「你又在高信心处翻车」。人格 = 原则冲突（`conflicts_with`）的 UI 化（v3 §3.3.3）。
- **全程单声道，案例可旁听**（裁决 2026-08-22）：所有反馈默认只有主教练一个声音，案例也是；案例节点的点评下方有「听听其他两位怎么看」折叠入口，点开才见（三声道内容仍需撰写，但只在 2 个案例节点）。
- **教练的三层声音**（裁决 2026-08-22：「用好 LLM 的特性，对话和解释的教练感很重要」的落法）：①**判分** = 规则引擎，永远（v3 §2.6 不动）；②**点评** = 创作期用 LLM 按人格批量生成、人工逐条审核后静态内置——运行时零延迟、零成本、零合规意外；③**「问教练」** = 答完题可追问一两句，轻后端代理 LLM 以主教练人格作答，上下文锁定本题材料与 canon，禁前瞻信号/个股建议/收益承诺（v3 §2.3），后端不可达时按钮隐藏、核心流程无损。③已裁决进 v0（2026-08-22），可降级。
- **学派成名案例**（裁决 2026-08-22，选材原则）：每个学派配其成名之作级别的历史案例——价值派的经典买入案、做空/法务会计的经典狙击案、行为派的经典泡沫案，第 2 章起按此选材（语料纪律不变：公有领域优先，v3 §4）。第一章的 Sunbeam 天然是风控派主场，三位教练共用。
- **错题档案是教练的记忆**：「你第 3 次在『应收激增 vs 账期变化』上站错边」这句话由主教练说出来——档案不是错题本，是教练对你的了解。
- 换教练随时可换（进度不变，只换声音）。

## 2. 支柱二：场景决策（情景 × 决策 × 反馈 × 重复，v3 §1）

**是什么**：训练的基本单元不是「知识点问答」，而是**历史实战场景里的一次决策**。每个场景都问到「所以你怎么做」，每次反馈都**评推理过程，不评历史结果**（v3 版本说明①：一个决策不因后来涨了就对、跌了就错——教练会明说这一点）。

**第一章（财报红旗，图已冻结）的决策形态**：
- 红旗题的决策词汇：可疑 / 不可疑 / **无法判断**（+信心）。
- **新增「决策转化」层**（本版变更）：两个案例节点在判断题之后追加一问——「你已持有这家公司，看到这些信号，下一步？」选项如：清仓回避 / 减仓并跟踪三个求证点 / 继续持有等下季报 / 信息不足先不动。评分看**过程**：求证点选得对不对、动作与你自己标注的信心是否一致（高信心喊可疑却选满仓不动 = 纪律失分点）。不改图结构，只在 2 个案例节点各加 1 题。
- 「纪律」在第一章的形态：教练点评固定三问——**你看到了什么（证据）/ 你怎么推的（过程）/ 你守没守流程（先替它辩护再下结论、信心与证据匹配）**。

**看多/看空、仓位大小 → 章节路线**（第一章装不下也不该装，它们是独立的图）：

| 章 | 主题 | 决策词汇 | 状态 |
|---|---|---|---|
| 1 | 财报红旗·收入的水分 | 可疑/求证/无法判断 + 决策转化 | 图已冻结，进行中 |
| 2 | 现金流 | 真实盈利力判断 | v3 §6 已列 |
| 3 | 经典场景·多空判断 | 看多/看空/观望（泡沫、崩盘、价值陷阱等历史案例） | 路线草案 |
| 4 | 仓位与风控 | 仓位大小、集中/分散、止损纪律 | ⚠️ 资金元素多，**法律评估前置**（v3 §2.2 中国侧刑事口警示，不可跳过） |
| 5 | 行为纪律 | 追涨杀跌、处置效应、结果偏差 | 路线草案（结果偏差是全产品的元能力候选） |

**训练形态的三级阶梯与红线**（裁决 2026-08-22：撤回本文旧版「永不做虚拟账户」的过宽表述——v3 §2.2 原文是「远期毕业场+法律评估前置」，不是永不）：
- **一级 · 单步判断**（第 1–2 章）：一个场景一次判断，无仓位状态。POC 全部在这一级。
- **二级 · 多步场景题**（第 3–4 章形态）：一道题内含连续几个时间步，**场景内**给你一个局部仓位，练止盈止损、加仓减仓——场景内有仓位，账户级无资金（不跨场景累计、无收益率曲线、无净值排名）。进入这一级的开发前先做一次法律评估（v3 §2.2 中国侧「模拟交易+资金元素」刑事口警示）：评估的是我们的形态离虚拟盘案例线多远、要避开哪些特征——是开工前查规范，不是不做。
- **三级 · 账户级模拟盘**：远期毕业场（v3 §2.2 原文），法律评估通过前不设计、不登记任何账户字段。
- **真正的永不只有两条**：永不输出前瞻信号、永不承诺收益（v3 §2.3）。历史场景的「后来发生了什么」只作尾声呈现，配教练台词：「结果不评判决策，过程才评判。」

## 3. 支柱三：多邻国化的节奏（轻快，但只抄可抄的）

多邻国化的是**节奏与颗粒度**，不是它的施压机制——hearts、榜单、confetti、推送催练在 v3 §3.4 是裁决过的不可抄项，不重开。落点：

1. **课节 = 3–5 分钟**：一个节点或一轮复训就是一节课，手机单手完成。
2. **每屏一动作**：教学屏不是阅读页——每屏一个点 + 一个微交互（点开对照、二选一小检查、拖一下滑块），末屏才是正式题。3–5 屏的契约不变（v3 §3.1），变的是每屏都在「玩」。
3. **即时反馈**：答完当屏出结果与教练一句话，绝不攒到最后。
4. **持续的进度感**：章进度条 + 图上点亮动画（沿用呼吸光效）+「今日复训 N 题」的轻目标（无推送，打开才看到）。
5. **连胜 = 校准连胜**：连续无「高信心翻车」的天数——奖励诚实，不奖励刷量（v3 §3.4）；反连击照录不罚（v0 只记录答题延迟）。
6. **快乐是克制的**：点亮那一下的光效 + 教练一句话点评，就是全部庆祝。
7. **UI 不照抄多邻国**（裁决 2026-08-22）：主导航仍是知识图（契约形态，v3 §3.1），另配**目录视图**——按域/层分组的清单式列表（投资目录的形态），显示锁定/点亮/复训到期状态，与地图一键切换。按图索骥或按目录打卡，各取所需。

## 4. 一次典型会话（5 分钟，把上面三条串起来）

> 小张午休打开链接。地图顶上：「复训 2 题到期」。
> **第 1 分钟**：复训题——「A 公司应收 +45%、收入 +12%，账期披露显示大客户从 30 天改到 90 天」。上周他在这个混淆对上把无辜的当成了红旗，这次他选「不可疑·比较有把握」。✓ 风控派教练：「对。上次你冤枉了它——记住，先看账期披露再喊抓贼。」
> **第 2–4 分钟**：新节点「让现金作证」。三屏：一屏一个点，第二屏让他亲手点开 Sunbeam 的两条线看缺口，第三屏做题——「红旗一阳性、现金流健康，你的结论？」他犹豫，点了一级提示（指方向），选「无辜解释概率大增·没把握」。✓ 得分按提示降档，但教练说：「用提示不丢人，瞎自信才丢人。」
> **第 5 分钟**：节点点亮，解锁「终局对决」。教练预告：「下一关，你第一课见过的那家公司会回来——这次你还要决定手里的仓怎么办。」进度条 12/14。他合上手机。
> ——没有爱心扣血，没有排行榜，没有烟花。有的是：一个记得他错误的教练，和一张越点越亮的图。

## 5. 用户流程（在 v1 基础上按支柱修订，未提及处沿用 v1）

- **首次进入**：落地即地图 → 首个动作是**选主教练**（三选一，各一句自我介绍）→ 两个源节点亮起。页脚三句声明常驻（v2 §5）。
- **节点学习流**：不变（3–5 屏 → 题 → 点亮；test-out；首答进档案）。教学屏按「每屏一动作」重写标准执行（第 2 步内容规范）。
- **案例流**：材料 → 判断题（+信心）→ **决策转化题** → 三声道教练点评 → （终局）揭示第一案身份。
- **复训流**：不变（HLR 固定权重特例、调度单位=混淆对、优先推上次站错的那一面），反馈由主教练署名。
- **完成与成绩单**（2026-08-22 修订）：完成页由主教练做总结陈词（预生成模板：引用档案里最典型的一次错误 + 校准分变化）。试用指标改为**轻后端匿名自动上报**（工程化规范 v2 §3/§7），「复制成绩单」保留为离线兜底与用户自留的总结页；about 页加一句「匿名使用数据用于改进产品」。

## 7. 机制细则

判分与数字全部沿用 v1 §5（信心三档 55/75/95、无法判断判分、提示降分 1.0/0.8/0.6/0.4、复训半衰期 1 天起 ×2/÷2、Brier Index+敢判率、85% 首答锚），此处不重抄。新增两条：
- **决策转化题评分**：动作与信心一致性 + 求证点命中，规则判分；无「唯一正确动作」时多个动作可满分（诚实优先于激进）。
- **教练文案契约**（2026-08-22 修订）：每题反馈 = 判分结果（人格无关）+ 人格点评一句（≤40 字）；案例节点三声道各 ≤80 字（默认折叠旁听）。点评文本创作期用 LLM 按人格批量生成、**人工逐条审核**（审核三查：无前瞻信号、无收益词、贴学派视角）后静态内置。成本封顶：每人格视角库 10–15 条 + 案例定制 6 段。「问教练」追问是唯一的运行时 LLM 面（§1 三层声音）。
