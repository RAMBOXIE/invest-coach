# 形态规格 v3 · 故事驱动

> **owner 指令**：「从一个个真实的故事出发，每个故事里让用户去决策判断，然后再引出这个判断的知识点。教练相当于是画外音一样持续陪伴。」「大胆重构甚至推翻重做……视觉呈现上也要有故事性，通过史诗般的体验让用户学习，彻底使用 LLM 重构学习的流程。」
> **依据**：8 路研究（叙事学习实证 / 叙事视觉 / 决策嵌入 / LLM 角色 / 故事素材正典 / 工程基准 / 红队 / 架构综合）。

---

## 1. 结论：方向成立，但按字面执行会失败

**支持的部分（有元分析级证据）**
- 「先在情境里判断、再给知识点」= PS-I，**g = 0.36** [0.20, 0.51]（53 项研究/166 个比较），高保真实施可到 0.58。
- 叙事对记忆与理解的优势：**g = 0.55**（37 项研究、33,078 人；记忆 g=0.72、理解 g=0.48）。
- 手机单人使用正是 narrative transportation 效应最强的场景。

**必须承认的反证（三条，决定设计走向）**
1. **故事本身不是学习增量的来源。** 严肃游戏元分析里「有叙事元素」的游戏**并不比没有的更有效**。起作用的是主动决策 + 紧跟的正典对照。
2. **「史诗般的体验」有实测负效应。** 与目标无关的有趣细节（seductive details）总体 **g = −0.16**、迁移 −0.12；高情绪唤起还会造成**记忆窄化**（中心记得牢、外周被冲掉）。
3. **知识会被绑死在故事上——这是默认结果，不是风险。** 单故事自发迁移率约 30%（无类比时仅 10%）；有研究显示学具体实例者即使被提示也可能无法迁移。

**所以本规格的形状是**：故事负责**动机与情境**，判断负责**学习**，正典对照负责**沉淀**，第二案例负责**解绑**。史诗感来自**尺度、黑场、原档质感、揭示节奏**——不来自形容词和背景故事。

---

## 2. 一句话验收判据（最重要的一条）

> **把故事文本全部删掉。如果选项仍然可判，它就还是答题工具，打回重写。**

反过来也成立：如果删掉故事后**无法判断**，说明故事承载了必要信息，形态才真正变了。

---

## 3. 一节 Episode 的骨架（6–9 分钟，一节只教一个判据）

分段推进由**用户点击控制**（learner-paced d=0.45 > system-paced 0.35）。每屏 ≤40 字，全程主动动作 ≥4 次。

| 槽位 | 时长 | 内容 | 依据 |
|---|---|---|---|
| **S0 冷开场** | 20–40s | 一屏：时间地点 + 一个具体的人的处境。**不给数据表、不给背景交代** | transportation；禁装饰细节 |
| **S1 情境事实** | 60–90s | 2–3 屏，**只给做出 S2 判断所必需的原档事实**（可展开 accession + 行号）。每屏 ≤1 个数字块 | contrasting case 的一半 |
| **S2 决策点** | 60–90s | 强制三选一，选项都要看起来合理；选完立刻标信心三档。**素屏**：叙事预算 ≤180 字 | prequestion 特异效应 g=0.54–0.66 |
| **S3 结果揭晓** | 30–45s | 历史上真实发生了什么（原档 + 官方认定）。**只呈现事实，不评判用户对错** | 产生「预测失误」的惊讶，不产生羞耻 |
| **S4 正典对照 = 知识点** | 90–120s | 画外音把**你的选择 / 常见的错法 / 正典判断**三者并排。**这里才第一次出现规则名** | PF 的巩固必须建立在学习者自己生成的解之上——**此槽位不可省，省了整个顺序不成立** |
| **S5 抽象渐隐** | 30–45s | 判据从故事里剥出来：一句公式化判据 + 一条边界条件 + **稳定抽象标签**（复训主键）。故事版/公式版/标签同屏出现一次 | concreteness fading 优于纯具体、纯抽象、反序 |
| **S6 第二案例对比** | 60–90s | 另一家公司的同构片段，只问一题：**「这两个案例哪里是同一回事？」** | analogical encoding，迁移率 **约 3 倍**——抗迁移失败最高杠杆，**不可裁** |
| **S7 出口** | 15s | 一句可带走的判据 + 排入 HLR 复训队列 | 已有资产 |

**S6 是我们已有资产的升级**：现在的「混淆对」正是同构案例对，只需把它从「复训题」提升为「显式比较任务」。

---

## 4. 四条不可让步的红线（红队要求）

1. **判断屏必须素屏**，叙事预算 ≤180 字——防叙事挤占认知资源。
2. **盲档模式为默认**：著名事件会泄漏答案 + 后见之明。题干从「结局题」改为**「原档可验证题」**；揭晓时回放你事前标的信心。
3. **剧情推进与对错解耦**：所有选项走向同一历史结局，**奖励只挂校准分**。分支做「单点分叉、立即汇合」——学习者控制的效应 g=0.05（近零），做树状分支是纯成本。
4. **在世真人只允许逐字引用其公开原话**，用第二人称把用户放进决策位，而不是虚构真人的内心戏。

**双层测量**：故事层不自适应、只做动机；**85% 锚 / HLR / 混淆对 / 锚题全部下沉到练习层**，锚题永久隔离、不进任何故事与任何 LLM 上下文。

## 5. 首批 5 个故事（按「能不能讲得下去」排序，不是按名气）

三条硬门槛：①有官方认定或公有领域正典；②关键数字能落到 accession + 行号 + sha256；③能挂到现有 14 节点。

| # | 故事 | 正典来源 | 教什么 | 挂到 |
|---|---|---|---|---|
| **1** | **雷曼 Repo 105**「季末那五天，资产去哪了」 | FCIC 最终报告（公有领域）+ Valukas 审查人报告 Vol.3。数字锚：季末移出 2007Q4 约 386 亿 / 2008Q1 约 491 亿 / 2008Q2 约 503.8 亿美元 | 期末窗饰、杠杆率 | `three-statements`（同一家公司两张表对不上）、`corroborate`、`falsification`（审查人原话「may not have been inherently improper」是标准的无辜解释，天然教鉴别诊断） |
| **2** | **巴菲特**「他自己承认的那笔烂交易」 | 数字：老 Berkshire FY1993 10-K，acc `0000950150-94-000443`，L379–380 / L2661（Dexter Shoe 对价 433,012 千美元）。原话：**FCIC 2010-05-26 访谈逐字稿，103 页公有领域** | 基率、证伪、清单 | `base-rate`、`falsification`、`checklist-after` |
| **3** | **硅谷银行 2023**「正表说有 160 亿，附注说少了 151 亿」 | SVB 2022 年报附注（EDGAR）+ 美联储 Barr 报告 + OIG Material Loss Review | 附注 vs 正表、摊余成本 vs 公允价值 | `three-statements`、`corroborate`、`base-rate` |
| **4** | **世通**「把电话费记成盖房子」 | 破产审查人 Thornburgh 报告 + SEC 民事和解 15.1 亿美元 + 2005 年定罪 | 资本化 vs 费用化 | `ocf`、`rf2`、`accrual-basis`、`corroborate` |
| **5** | **瑞幸**「1.23 亿张券」 | SEC press release 2020-319（1.8 亿美元罚款）+ 中国证监会/财政部认定（虚增收入 21.19 亿元，占披露收入 41.16%）+ 市监总局 6,100 万元 | 刷单造假 → 收入质量 | `growth-rate`、`receivables`、`rf1`、`corroborate`、`falsification` |

**关于巴菲特的关键发现**：想让他在产品里长篇说话，**用 FCIC 访谈逐字稿，不要用股东信**（股东信署名版权属个人，随 SEC 备案也不改变）。1964 伯克希尔 / 1973 邮报 / 1988 可乐早于 EDGAR，**不做判分数字**，只当过场。

**明确排除**：Wirecard（刑事审判 2026 年仍未判，讲人即违约束）｜Theranos（无 EDGAR 财报，与财报红旗图不相交）｜GameStop（诱导交易冲动，撞产品红线）｜南海泡沫/日本泡沫（无可溯源原档数字，只能当幕布）。

**一个必须先解决的技术坑**：**FCIC 正文 PDF 的数字提取是坏的**——实测 govinfo 版与 Stanford 版正文的阿拉伯数字在文本层全部丢失（尾注正常）。取数必须走 FRASER 逐字稿 / 听证会 transcript / 页面图像 OCR + 人工核定，**禁止直接抽正文**。

## 6. LLM 的确切职责（回应「彻底使用 LLM 重构学习流程」）

**定位**：LLM 是**排版工 + 旁白演员 + 作者工具**，不是叙事者、不是裁判、不是事实来源。故事骨架（哪一年、哪家公司、哪个数字、哪个决策点、正确判断）由取数管线 + 人类编辑确定并**冻结**；LLM 只在冻结骨架上做表层实现与语气个性化。

> **LLM 彻底重构的是流程与呈现，不是内容真值。** 这样 owner 的第 3 条与既有裁决才能共存。

**能做（5 项，风险从低到高）**
- L1 旁白渲染：把已核定的 beat 卡渲染成 ≤2 句（40–80 字）画外音
- L2 判分后的语气变体：输入全是结构化枚举（选项 id + 规则判定 + 信心档 + 混淆对 id），输出同一结论的不同说法，**不改结论、不加新事实**
- L3 换一种说法：对已冻结知识点做重述/类比，禁止引入新实体与新数字
- L4 苏格拉底追问：从预置问题库**选**一条并人称化改写（选择权在检索层，措辞权在 LLM）
- L5 **离线作者工具（价值最大、风险最低，应优先做）**：批量生成候选旁白/干扰项/类比，**100% 人审后入库**——这是唯一允许 LLM 接触新内容的位置

**不能做（写进 validate.py，不是写进 prompt）**
- 生成或改写任何数字、日期、公司名、财报科目、比率——一律槽位注入
- **第一人称扮演真实历史当事人**。教训是机制性的：模型为语气友好会自动生成自我辩解与责任消解。教练只能是学派化身，**说「格雷厄姆学派会问」，不说「我是格雷厄姆」**
- 判分、给对错、决定分支跳转
- 读取用户自由文本
- 任何前瞻性/收益承诺/买卖建议

**确定性护栏（全部在 LLM 之后跑）**：①数值 token 必须 ⊆ 该 beat 的 facts 白名单 ②公司/人名/机构必须 ∈ 该 beat 实体集 ③逐句 NLI 校验 ④JSON Schema 约束解码 ⑤禁词/禁句式 ⑥**三级回退**——每个 beat 必须有人工预写的 `default_narration`，LLM 超时/失败/校验不过即静默回退，**回退路径保证 100% 可离线**。

## 7. 数据结构（三层）

```
Layer 0  事实层（已有，不动）
  content/<case>/facts.json   ← accession + 行号 + sha256，数字唯一真源

Layer 1  故事骨架层（新增，人写 + 冻结，本次重构的真正工作量）
  content/stories/<case_id>/case.json = {
    case_id, era, hook,
    beats: [{
      beat_id, facts_ref[],                 // 该幕允许出现的数字/实体白名单
      decision: {options[], rule_id},       // 先决策
      knowledge_ref,                        // 后知识点（挂到 14 节点之一）
      default_narration,                    // 必填：回退与离线用
      forbidden_terms[]
    }],
    twin_case_ref                           // S6 的同构第二案例
  }

Layer 2  叙事外壳层（运行时，可完全失败）
  LLM 生成 → 六道护栏 → 不过则回退 default_narration
```

## 8. 迁移路径（不推倒重来，只推翻展现层与内容组织层）

**重做边界：保住证据层与判分层，推翻展现层与内容组织层。**

| 步 | 内容 | 可独立上线 |
|---|---|---|
| **0** | 落 `SPEC_DEV.md`：tokens.json + STRUCTURE.md + preflight + 拆 `src/parts/` + 补 `check_a11y.py`/`check_budget.py`，并修 §10 的 5 处存量违规 | ✅ |
| **1** | **一幕垂直切片**：用现成的 Sunbeam FY1997 + Dell FY1998 做「1998 年 4 月，你是投委会前唯一读完 10-K 的人」，S0–S7 全做完，在中端安卓 + 微信里跑通性能与可读性。**不要先批量改 14 个节点** | ✅ |
| **2** | 与旧形态 A/B：主看三个指标——85% 锚是否维持、beat 完成率、揭晓未结算率 | ✅ |
| **3** | 铺开首批 5 个故事；史诗章总数封顶 4–6 个，微案例目标 ≥42 个（3 情境 × 每知识点，含 1 个假阳性例） | ✅ |

**必须保住的现有资产**：facts.json 数字账本、L1–L4 出处契约、`x_prov` 签字与 hash 绑定、规则判分引擎、HLR 复训、Brier 校准分、混淆对（升级为 S6 的比较任务）、锚题机制、单文件离线。

## 9. 需要 owner 现在裁决的两件事（不能由实现层含糊过去）

1. **「剧情不作为奖励」**——所有选项走向同一历史结局，奖励只挂校准分。这与「史诗爽感」直接冲突：用户会期待「我选对了所以故事变好」。红队认为不解耦就会出现「为推进剧情而乱选」，判断训练失效。**我倾向解耦**，但这是体验取舍，你定。
2. **教练是否读用户自由文本**——方案 A：保留既往裁决（自由文本不进 prompt），陪伴感有上限；方案 B：撤销该裁决，+15–20 人天，并**永久引入幻觉与提示注入面**。**我倾向 A**。

---

## 10. 必须向 owner 坦白的一点

**故事解决的是动机与情境，不解决重复练习的形态。** 练习层（间隔重复、混淆对复训、锚题）仍然会「像答题工具」——这是当前证据下**无法用叙事消除**的部分。真正的改变是：练习层从此是**你已经在故事里做过一次判断之后的巩固**，而不是产品的第一印象。
