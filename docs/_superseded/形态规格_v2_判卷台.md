## 1. 手机优先的信息架构

**首屏 = 今日案卷，不是图谱。** 底部三 tab：`今日 / 档案 / 我`。

- **今日**（默认落地）：今日一案大卡（代号 + 钩子 + 预计分钟 + 开始）｜复训到期横条（30 秒一道）｜一行进度细字。
- **档案**：能力体检——只读图谱缩略图 + 分组列表 + 校准分 + 错题档案（按混淆对聚合）。
- **我**：教练切换、AI 披露、进度码导出/导入、清本地草稿。

**图谱在手机上留，但不当导航**：降为只读缩略图，点节点只弹 canon 卡；导航职责交给「今日」调度器。理由是硬的——640px 下节点已压到 88px，第二章 30+ 节点必崩，且 pan/zoom 与「一屏一动作」冲突。**桌面端保留原图谱为主导航**，同一份 site.json 两套渲染。

### 替换 vs 缩小（手机版的核心表）

| 桌面元素 | 手机处理 | 判定 |
|---|---|---|
| pan/zoom SVG 图谱 | 竖向路径列表；SVG 降为只读全景 | **替换** |
| HTML 表格（两行数字对照） | 指标为行、实体为列的 2 列窄表 + 步差高亮 + 对照条 | **替换** |
| 多年数据 | small multiples 迷你折线 + 一行派生倍数 | **替换** |
| hover tooltip（canon/出处） | tap 溯源徽标 → 底部抽屉 | **替换** |
| 复选框式「理由多选」 | 材料上的可点 chip + 底部证据槽 | **替换** |
| 三声道教练并排 | 单声道 + 「听听其他两位」抽屉 | **替换** |
| `<details>` 折叠、三级提示、进度条 | 保留（≥48px 触控、抽屉化） | 缩小即可 |

**否决的流行形态**（有反证或无证据）：Tinder 式左右滑（奖励直觉快答，与「慢下来标信心」直接相反）；长按对比（不可发现 + 与文本选择冲突，改 tap 切换）；聊天气泡承载诊断（对照证据偏负面，认知负荷更高）；scrollytelling 承载判分材料（参与度改善但**理解正确率与其他格式持平**，只用于终局揭示叙事）。

**工程红线**：所有排序/归位一律 **tap-to-place + ↑↓ 按钮**，拖拽只作增强（WCAG 2.5.7 要求拖拽必须有单指非拖拽替代）。

## 2. 一节课的骨架（判卷七拍）

深层节点（带 `x_level` 的红旗/案例节点）走全流程；5 个基础概念节点退化成**两拍**（材料 → 结论），这是分层设计不是缺陷。

| 拍 | 屏 | 学习者做什么 | 谁判 |
|---|---|---|---|
| ① | 案卷材料 | 读对照卡；tap 溯源徽标看原档出处 | — |
| ② | **先写 15 秒** | 用自己的话说：可疑吗？凭什么？（语音优先，**纯本地，一个字不上行**） | 不判分 |
| ③ | **挑证据** | 从材料里点出你依据的那几条（chip → 证据槽） | 规则引擎 |
| ④ | **排除辩护词** | 三条无辜解释逐条判定：排除了 / 没排除 / 材料不够 | 规则引擎 |
| ⑤ | 下结论 | 三选 + 信心三档 | 规则引擎 |
| ⑥ | **自评对照** | 闭集勾选「我刚才想到了哪些要点」→ 与③④的实际选择对撞，得出 **hindsight gap** | 规则引擎 |
| ⑦ | 批注回卷 | 四个**可计算属性**的反馈 + 专家链对照（后置）+ 可选追问 | 规则引擎算，LLM 挑签字文案 |
| ★ | **闭卷锚题** | 换公司、换壳、对话中未出现过的迁移题 → **唯一的点亮条件** | 规则引擎 |

**②+⑥ 这一对是本规格的枢纽**：把自我解释的收益（g≈0.55，来自**生成**本身而非被批改）拿到手，同时把它转成闭集信号——**全程不需要任何 LLM 读原文**。这是裁决 5 下 step-based 唯一走得通的路径。

**⑦ 的步级反馈怎么做到「不判分而有信息量」**：把「评判」换成**关于你自己作品的四个可计算属性**，全部由规则引擎从结构算出：
- **覆盖**：触到了几条正典要点
- **区分**：你的证据能不能分开混淆对的 a 与 b
- **顺序**：有没有在求证前定罪
- **一致**：信心与证据条数是否匹配

加三种非评判性体裁：**后果预演**（「按你这条链走下去，下一步你会去查 X——而账期披露不在你的链里」）、**对照叠加**（专家链半透明覆盖，永远后置于你的作答）、**当场反事实**（「把这张卡拿掉，你的结论还成立吗」→ 立即重渲染）。依据：详述型反馈 EF 0.49 vs 只判对错 KR 0.05。

**锚题的双重隔离**（红队要求）：`seen_in_dialog == false` **且** `case_id ∉ 本次用过的案例`——**锚题必须换公司**，否则点亮的是「记住了 Sunbeam」而不是「掌握了这个节点」。

## 3. LLM 的确切职责（裁决 5 的完整落点）

**输入面铁律**：prompt 里只允许出现三样东西——① 记忆 schema 的闭集摘要（全是 enum id 与整数）② 当前节点/题目 id 与规则判分结论 ③ 已签字内容的 id 列表。**用户键盘产出的任何字符都不上行**；「先写」原文存独立 localStorage 键 `ic:draft:<quiz_id>`，不进记忆、不进遥测、可一键清除。

**准许的四件事**（全部闭集进、闭集出）：
1. **排课**——今日路径的节点/变体 id 序列
2. **选文案不写文案**——输出「展示哪条已签字文案的 id」
3. **chip 排序**——从签字 chip 池里挑 3–4 个 id
4. **时事外壳组稿**——把已核定的事实卡排成导语；数字作为**不可变载荷透传**，上屏前过确定性校验器（数字 exact match + accession 命中 facts.json），不过就静默回退原文

**永久禁止**：读用户自由文本 / 判分或改判 / 生成任何数字或公司名 / 写即席的用户可见正文。

> **上一版提案 §3③「LLM 读先写文本 → 输出闭集标签」在裁决 5 下作废**，由「自评 checkbox」替代。
> **被低估的红利**：运行时 LLM 调用从「每对话轮 1 次」降到「每会话 1–2 次」→ 首字延迟离开关键路径 → 上一版「必须用 Workers 代理、不能隧道回源」的延迟决策**失效**，可直接用 named tunnel 回自己的机器。架构简化一档，成本从「按轮」变成「按会话」。

## 4. 双轨语料：时事怎么做而不制造法律敞口（裁决 4 的落点）

**核心化解**：把「时事性」的来源从**市场传闻**换成**监管刚发出的公开问询**。

### A 轨 · 已认定案例（唯一允许出现定性结论的地方）
只用 SEC AAER、证监会行政处罚决定书、生效判决。Sunbeam FY1997 / Dell FY1998 已在此轨。定性结论一律以认定文书原文呈现，我们不加一个字。**锚题必须出在 A 轨**——只有 A 轨有权威标准答案。

### B 轨 · 在世公司 + 当期时事（只教「监管在问什么」）
语料 = **SEC comment letters（UPLOAD/CORRESP）** + 交易所问询函与公司回复。

**决定性的法律事实**：SEC 官方文件白纸黑字写明——「函件仅陈述工作人员就特定文件的立场，**不构成委员会意见的正式表达**」「不应被解读为确认存在或不存在任何调查」。所以「SEC 就 X 向 A 公司提问」在法律性质上与「我们指控 A 公司 X」是**三个不同的言论主体、三种不同的责任基础**。函件在审阅结束后 **20 个工作日**公开——拿到时往来已结束，不存在干预进行中程序的问题。

**五条硬约束（写进产品，不是写进文档）**：
1. **三件套必须同框才出题**：官方提问原文 + 公司回复原文 + 原档数字（accession + 行号 + sha256）。缺任一不出题。
2. **题干只能问机制，不能问定性**。允许：「监管为什么盯这个科目？」「哪些特征会触发这类提问？」「公司的回答回答了什么、回避了什么？」**禁止**：「这家公司是否造假？」
3. **每屏固定签字免责文案**（预置，不进 LLM），直接引用 SEC 原句。
4. **不做匿名化**——法律上无效（of and concerning 不要求指名）、技术上必然可逆（EDGAR 全文检索 + XBRL frames）、事后看像刻意规避。改走「具名 + 官方出处 + 公司回复同框」。
5. **未结案的立案调查一律不进 B 轨**，结案后并入 A 轨。

### 地域取舍
**B 轨优先做美股。** 不是因为美国法更宽松，而是风险层数不同：美国是「一层民事 + Milkovich 宪法保护 + anti-SLAPP + SEC 自带官方免责语」；中国是**四层叠加**——民法典 1025/1026（且 1998 年那条「如实报道国家机关公开文书不构成侵权」的明文安全港**已于 2021-01-01 废止**）+ 刑法 221 条的**程序性风险**（鸿茅药酒/谭秦东先例：构成要件不成立也可能被跨省抓捕）+ 证券法 56/193 条与刑法 181 条（口径含**「误导性信息」**，真数字配错误框架也可能落入）+ 非法证券投资咨询。
A 股问询函的语料质量其实更高（中文原生、命中应收与收入确认更准），但**点名在世 A 股公司的单案教学暂缓**，先只做不点名的统计式教学（「2024 年交易所问了 N 次商誉减值，问法长这样」），直到拿到中国执业律师书面意见。

### 三个产品侧硬控制
- **LLM 不得生成公司名**——与官方文书一样只能从白名单语料带出。
- **「教练口头推演·非正典」这一档禁用于在世公司的定性话题**：可以推演会计机制，不可以推演「这家公司在做什么」。
- **建 takedown 通道 + 版本化撤回**：某在世公司来函后 24 小时内可下线该题并保留原档留痕。

### 必须由真人律师补的五处空白（不要当成法律意见）
① fair report privilege 是否覆盖 SEC comment letter——各州标准不一，**未找到任何直接判例**，这是 B 轨最大空白；② CORRESP（公司撰写）的版权与合理使用边界（建议大段只引 UPLOAD，引 CORRESP 时短引 + 链接）；③ 中国民法典生效后是否有替代 1998 年解释第六条的明文规则；④ 付费的财报教育点评在世 A 股是否触及非法证券投资咨询；⑤ 各州 anti-SLAPP 覆盖范围与原告择地能力。

**成本结构的教训（比法条更重要）**：St. Jude v. Muddy Waters——**结论后来被 FDA 证实是对的，官司仍打了 17 个月**；Gradient Analytics 因**保险耗尽**被迫公开道歉和解。**胜负与对错脱钩，续航力决定结局。**

## 5. 时事语料管线（技术可行，核心筛选零 LLM）

| 层 | 频率 | LLM | 内容 |
|---|---|---|---|
| L0 采集 | 每日 02:00 ET | 无 | daily-index（1 req）+ AAER RSS（1 req）+ EFTS 全文检索（每周 100–200 req）。UA 带联系邮箱，**限速 5 req/s**（官方上限 10，留一半余量） |
| L1 确定性指标 | 每周 | **无** | XBRL frames + companyconcept 重算红旗指标 |
| L2 权威绑定 | 每周 | 无 | 每个候选必须命中官方文书才准出题（A 档 UPLOAD / B 档 AAER / C 档公司自认重述） |
| L3 组稿 | 人工触发 | 有（只挑不写） | LLM 挑混淆对与叙事外壳，数字透传 + 校验器 |
| L4 签字 | 人工 | 无 | G1/G2 门，`x_prov` 绑 hash |

**L1 的五道防呆**（每条都由实测反例逼出来）：① 两期同 tag（去掉 2.1% 的跨年 tag 漂移）；② **不信 frames 的 val**——回 `companyconcept` 取原始申报值重算（专杀 +17,481% 那类假红旗）；③ **经营现金流走差分**（10-Q 是 YTD 口径，单季 OCF = 6M YTD − 3M YTD）；④ 规模下限（当季收入 ≥ $1 亿、应收 ≥ $500 万）；⑤ 排除 SIC 6xxx 金融业。
**实测产出**：2237 家可比 → 106 家（仅规则）→ 加防呆后 **30–60 家/周**。

## 6. 学习者记忆（零自由文本，裁决 5）

每个字段只能是**受控枚举 / 整数 / 定点小数 / 时间戳 / 白名单 ID**。

```
v:2, learner:{device, started, tz_off}
pairs:      {<pair_id>:{seen,wrong,hl,due,last_side,conf_when_wrong}}
steps:      {<node_id>:{evidence:{n,hit,miss,distractor},
                        ruleout:{n,ok,over_exclude,under_exclude},
                        conclusion:{n,ok,na_honest,na_dodge}}}
calib:      {n,sum,brier_index,streak,best,overconf_events,underconf_events}
misconcept: {<mis_id>:{hits,last_ts,src:selfcheck|ruleout|evidence}}
anchors:    {<node_id>:{attempts,passed_at,case_used}}
```

**一条期望值下调**（重要）：有 N=259 的反证显示「按个人混淆模式精确排序」相对「随机交错」**没有增量**。所以工程预算不要压在更聪明的选题算法上，压在 ① 误解库质量 ② 必然交错 + 必然对比呈现 ③ 到期复训 这三件上。

## 8. 红队要求的必备防护（摘要）

- 时事题一律带 `x_case_status`（`settled` / `regulator_asked` / `none`）；`none` 不得配任何红旗话术。
- 动态生成内容一律 `generated:true`：**不进错题档案、不进复训队列、不计校准分、不做锚题**——绝不能让 LLM 编错的题被间隔重复系统强化（红队认定的最坏单点后果）。
- 微信内核清 localStorage 是**形态级冲突**：必须提供「进度码」导出/导入（短码，可截图），并在微信内打开时主动提示。
- 锚题库每节点 ≥2 变体，防背题；锚题失败不惩罚，只回到练习。
