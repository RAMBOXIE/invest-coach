## 3. 轻后端（本版核心新增）

**职责只有两个，其余一概不做**（无账户、无内容下发、无判分——判分永远在前端规则引擎，v3 §2.6 不动）：

1. **匿名遥测**：`POST /api/v1/events`——前端批量上报事件（首答/复训/点亮/信心/提示/决策转化/会话时长），载荷 = `{device_id(前端生成 UUID), schema_version, events[]}`。append-only 落库。十人试用的验收指标（≥6/10 完成、复训参与 ≥50%）由此自动统计，成绩单降为离线兜底。
2. **「问教练」LLM 代理**：`POST /api/v1/ask-coach`。**护栏按《知识可靠性与LLM边界_v1.md》§7 全套实现（2026-08-22 红队 16 例后的重设计，取代本条旧描述）**，要点：正向白名单（只能建议再看什么数据，永不建议对钱做什么）；前置分流在进模型之前拦（个股代号/第一人称持仓/当下/前瞻/收益/身份 → 固定话术不进 LLM）；五条硬规则每轮在历史后重申（无新数字阈值、不谈材料时点之后、不连收益、不扮演分析师、不删限定语）；**禁改判**（注入本题规则判分结论+fb，不得暗示判分有误——v3 §2.6 的运行时锁）；被问身份逐字输出教练 x_identity；上下文预算 4k 封顶超出报错不截断；node_id 白名单、空材料返 503；「作答摘要」只收结构化枚举、用户自由文本理由永不进 prompt；输出强制简体中文散文，违规降级固定话术；未通关终局前注入材料剔除公司真名（剧透门控）；对话历史上限 2 轮。发布前必跑红队对抗测试集（16 问句集入 `docs/review/`）。限流定性修正：每 device 每日 20 问是**成本控制不是安全控制**（device_id 可重置），安全侧 = IP+device 双键 + 全站日调用熔断 + 输入长度与 max_tokens 封顶。

**技术选型（成本从简 + 未来可扩，对应 owner「初期规划考虑更多用户」）**：
- **Go 单二进制 + SQLite**（纯 Go 驱动免 cgo）。选 Go 的理由：作者主栈（xtrader 后端即 Go），运维=拷一个文件。
- **扩展路径设计在今天、实现在将来**：DSN 环境变量切换 SQLite→MySQL（schema.sql 双兼容）；events 表 append-only 天然可分区归档；`device_id` 旁预留可空 `user_id` 列（将来接账户不迁表）；服务无状态可横向扩（限流表将来外置 Redis）；API 带 `/v1/` 版本号；载荷带 `schema_version`。
- **CORS 与 file:// 兼容**：请求用简单 POST（`text/plain` 避免预检），服务端接受配置内的站点 origin 与 `null` origin（file:// 双击场景）。
- **部署（已裁决 2026-08-22：免费方案）**：后端进程跑在现有常开机器上，**cloudflared named tunnel**（免费）绑定固定子域出 HTTPS；quick tunnel（trycloudflare，无需账号）地址每次变，仅临时联调。前端把后端地址作为构建常量注入，换地址重构建即可（秒级）。单实例。
- **隐私（2026-08-22 修订）**：遥测=匿名使用数据；**「问教练」输入是用户主动输入的文本，按敏感数据管理、不冒充匿名数据**——面板首次打开明示「回答由 AI 实时生成，仅解释本题材料；你的提问会被留存用于质量与合规复查」，保留期 90 天定时清理，落库前对金额/证券代码/联系方式打码，输入框常驻提示「请不要输入个人信息或你的真实持仓」；日志库所在机器全盘加密、不进 git、备份不出机。

**教练点评的两级 LLM 用法**（体验 v2 §1「三层声音」的工程侧）：
- **创作期**：人格点评文本用 LLM 按人格批量生成 → 人工逐条审核 → 静态写入 site.json（运行时零延迟零成本）。生成脚本挂在内容管线里（§6）。
- **运行时**：仅 /ask-coach 一个面。进 v0 还是 v0.5 待 §10.③。

## 4. 数据契约（site.json）

基契约与 `x_` 登记制同 v1（SCHEMA.md 为登记簿，校验器白名单强校验，未登记即 ERROR）。已登记汇总：
- 顶层：`x_note` `x_version` `x_coaches`（含 `canon_sources` 学派出处、`style_lines`；人格字段不用真人名，出处字段必须真名真书）`x_review_bank`。
- 节点：`x_qtype`（合法值含 `决策转化`）`x_level` `x_pairs[].id` `x_coach_notes`。
- 屏/题：`x_covers` `hints×3` `opts[].na` `confidence` `x_pair`。
- **负面契约**：第 1–2 章白名单不含仓位/账户/收益率字段；场景内仓位字段随第 3–4 章设计与法律评估登记；账户级字段远期毕业场前不登记（v3 §2.2/§2.3）。

## 7. localStorage 与遥测事件

- localStorage 同 v1（单 key `invest-coach:ch1`、首答不可变、隐私模式静默降级），新增 `device_id` 与 `coach_id`（当前主教练）、`pending_events[]`（离线暂存，联网补发）。
- 遥测事件（2026-08-22 修订为可归因契约）：载荷必带 `content_version`（site.json x_version）+ `build_sha`（构建注入的内容 sha256 前 8 位）；`first_answer`/`review_answer` 必带 `quiz_id`（= quiz.x_id）+ `pair_id` + `side` + correct/confidence/hints_used/na/latency_ms；新增屏级事件 `screen_view`（node_id+screen_index+停留时长）与 `screen_abandon`。事件全集：`session_start/end` `node_open` `screen_view` `screen_abandon` `first_answer` `node_lit` `review_answer` `decision_convert` `ask_coach` `chapter_complete` `scorecard_copied`。**缺 quiz_id/side 的答题事件视为契约违规**——85% 锚、区分度、混淆对误伤率全按题聚合，试用后补不回来。
- 成绩单保留：完成页/档案页可复制（离线兜底 + 用户自留总结）。
