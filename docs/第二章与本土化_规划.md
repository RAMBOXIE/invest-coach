## 一句话现状

- 第一章:15 节点 / 108 题 / 4 个真实案例幕 / 3 卷实验区。**全部围绕「收入的水分」的异常识别,
  案例全是美国公司,正样本只有 Dell 和 Moderna 两个陪衬。**
- 这正是 ROADMAP 点名的内容配比短板:「调研支持机制,不支持内容配比 —— 全是造假案、没有干净公司。」

## 铁律约束(决定整个计划的形状)

**事实不出自 LLM。** 真实公司数字只能来自原档 + sha256 + 人工核定(`docs/知识可靠性与LLM边界.md`)。
现有 evidence 管线全部围绕 **SEC EDGAR** 建(accession + EDGAR URL + 行号 + sha256)。

这一条把「本土化」劈成两半,规模差一个数量级:

| 案例 | 上市地 | 原档在哪 | 能否走现有管线 |
|---|---|---|---|
| **瑞幸咖啡** | 纳斯达克(至 2020-07)| EDGAR:CIK 0001767582,20-F + SEC 认定书 2020-319($180M)| **能,直接走** |
| 康美药业 | A股(深交所)| 巨潮资讯网 cninfo.com.cn | 不能,要新管线 |
| 乐视网 | A股(深交所,已退市)| 巨潮资讯网 | 不能,要新管线 |

**结论**:瑞幸是唯一能用现有管线的中概股造假案,也是中文公共记忆里最响的一个。
A股案例(康美/乐视)需要一整套新取数基础设施(巨潮爬取 + 中文原档核定 + 新的 accession 命名),
其工作量与现有整个 EDGAR 管线相当。**这三件事必须分阶段,不能并做。**

## 分三阶段,按依赖排序

### 阶段 A —— 瑞幸案例(能立刻做,验证「本土化案例」这条路)

**为什么先做**:走现有 EDGAR 管线,零新基础设施;是中文散户代入感最强的造假案;
一个案例就能验证「换成中概股,用户完成率/共鸣是否变化」(呼应 ROADMAP「最该先验证的三件事」之二)。

**做什么**:仿照现有四幕,做第五个真实案例幕 `luckin-2020`。
- 原档:瑞幸 20-F(2019 财年,造假期)+ SEC 认定书 2020-319 + 罚款令。入 `evidence/` + sha256 + R28 登记。
- 当事人:走 ADR-0004/0005,具名 CEO/CFO 说当年公开原话(20-F、业绩公告),锚到原档行号。
- 数字账本:虚构销售 $3 亿、虚增费用 $1.9 亿等,逐条核定进 `facts.json`。
- 教学点:与 Sunbeam 呼应但不重复 —— 瑞幸是「关联方虚构交易」,不是「应收跑赢收入」。
  它教的是**收入本身的真实性**,是第一章异常信号之外的新一类。
- 门禁:过 `validate --stories`(S1–S9)、`check_style`、`check_coach`;新幕需人工签字。

**产出**:1 个新幕。这是 ROADMAP 验证清单能立刻投放的素材。

### 阶段 B —— 第二章图设计(与 A 并行规划,但填内容在 A 之后)

**主题**:**正样本主线 —— 怎么判断一家健康公司的财报好不好。**
第一章教「抓假账」,用户学完只会证伪。第二章教「证实」:一家正常公司,它的财报好在哪、
增长是不是真的、赚的钱是不是可持续。这是 ROADMAP 内容配比短板的正解。

**候选知识节点(待审图冻结,不是最终)**:
- 毛利率与费用率:赚钱能力,和同行/自己历史比
- 自由现金流:利润之外,真正能拿走的钱
- ROE 杜邦拆解:高 ROE 是靠真本事还是靠杠杆
- 存货与预付:健康公司这两项怎么动
- 分红与回购:公司怎么对待股东的钱
- 护城河的财务痕迹:定价权、客户粘性在数字上长什么样(呼应 Buffett 幕)

**正样本案例**:健康公司的复盘。候选:贵州茅台(A股,巨潮)、腾讯(港股)、
或先用能走 EDGAR 的美股(苹果/微软的某一年)过渡。**案例选谁依赖阶段 C 的取数能力。**

**流程**:先出图规划 → owner 审图冻结(`ch2-graph-v1`)→ 才填内容。**不跳过审图。**

### 阶段 C —— A股取数基础设施(最大,单独立项)

**做什么**:把 evidence 管线扩展到支持巨潮资讯网的 A股原档。
- 新 accession 命名规范(巨潮没有 EDGAR 那套编号)
- 中文原档的行锚定与 sha256(现有 S7 的英文/PDF 逻辑要扩到中文)
- `fetch_current.py` 或新脚本支持巨潮检索
- `facts.json` 的 `evidence_files` 支持非 EDGAR 来源

**没有这个,康美/乐视只能靠 LLM 编数字 —— 正好踩铁律,绝对不做。**
这是纯基础设施,规模最大,应该在阶段 A/B 验证「本土化案例有效」之后再投入。
