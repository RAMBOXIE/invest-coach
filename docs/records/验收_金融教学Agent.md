# 验收自检：这是不是一个「金融教学 Agent」

> 2026-09-03。owner 给的验收标准只有一句：**它是不是一个金融教学 Agent。**
> 产品定义（owner 原话）：「AI 投资教练：基于真实投资经典事件（如财报解读，巴菲特判断等），
> 使用 LLM 推演和教练用户学习更好的投资知识和习惯。LLM 会扮演当时事件中的关键决策人
> 和用户一起讨论为什么当时有这样的决策。」
>
> 下面按这句话的四个部件逐条对照现状。写的是实情，不是目标。

## 1. 「基于真实投资经典事件」 —— 成立

- 四幕：Sunbeam 1998（财报舞弊）、Lehman 2008（Repo 105）、Buffett 1993（Dexter，他自己写过的失误）、
  Nikola 2021（分母为零）。全部数字绑到 SEC EDGAR 申报号与行号，引文带英文原文并由机器逐字核对（S7/S7c）。
- 十四份原档归档并锚 sha256（R28），账本 44 条已核定事实。
- 用户在幕里**先判断、再揭晓**：reveal 之前的拍不许出现结局词（S9），判分看的是动作与当时证据是否相称，不看后来涨跌。

**缺口**：四幕里只有 Sunbeam 有完整的当事人陈述链（3 条陈述 + 追问 + 出证），Buffett 与 Lehman 各 1 条，
Nikola 0 条。「和当事人讨论」这个机制在三幕里材料很薄。

## 2. 「教练用户学习更好的投资知识和习惯」 —— 骨架成立，是**规则**在教，不是 LLM

现有的教练闭环（check_coach C1–C13 守着）：

| 环 | 现状 |
|---|---|
| 诊断 | 每个错误选项标一个真实误解（19 类，227 个选项全标注）；同一误解跨题聚合两次即触发 |
| 处方 | 处方是纯函数，进队列排在课程之前，带理由；四条触发：误解聚合 / 过度自信 / 复习到期 / 实验区跳查 |
| 判分 | 确定性规则（ADR-0001），离线可用、可复现、可回放 |
| 校准 | 信心三档 + Brier 分；过度自信有后果（提前召回并清算） |
| 迁移 | 点亮唯一入口是闭卷题：换一家公司、没见过的材料、不给提示 |
| 复习 | HLR 间隔重复，错题档案按混淆对聚合 |
| 习惯 | 实验区考「接下来你会去查什么」，越界项各附「这份材料为什么答不了它」 |

这一套是一个教学系统该有的形状。但**「使用 LLM 推演和教练用户」这半句，在今天之前几乎不成立**：
LLM 只在两处出场——追问台挑一条原话（输出一个 id），以及先写屏读你写的那段（两三句）。
处方、反馈、误解诊断全是人写死、规则触发的。它可靠、可复现，但它不「推演」。

## 3. 「LLM 扮演关键决策人，一起讨论为什么当时有这样的决策」 —— **今天之前不存在，今天建了第一条通道**

之前的追问台是**查表**：你问一句，LLM 从他写过的话里挑最贴的一条给你看。他不会解释，不会被追问出理由。
2026-08 放弃了自由散文（登记簿 #5），因为要靠提示词去堵一个开放集合。

今天建的 #10（ADR-0004）把散文放回幕里，靠的不是模型自觉，是三道确定性的闸：

- **材料闸**：模型只看得见 reveal 之前的当年材料（他的陈述、追问与出证的原文、证据卡）。结局不在里面。
- **出口闸**（`check_discuss`）：数字必须出现在材料里；后见之明词（后来 / 最终 / 重述 / 破产 / 被认定…）、
  荐股措辞、「我是 AI」式出戏，任一命中整条丢弃，回落到逐字匹配。变异测试 7/7。
- **标注闸**：屏上红字「LLM 扮演 · 某某说」，明写不是原档逐字；带行号的陈述仍然只来自 case.json。

**但要说清楚：这条通道今天只在无 key 的后端上验过接线**（请求打到、正确回落、输入框复位、无报错）。
**它还没有在真模型上跑过一轮。** 提示词的口吻、出口检查的误杀率、他会不会在追问下编动机，
都要拿真 key 跑十几轮对话才知道。这是下一步，不是已完成。

## 4. 「财报解读、巴菲特判断」 —— 财报解读是全部，巴菲特判断只有一幕

第一章 15 关全是财报解读（收入的水分）。「巴菲特判断」只有 Dexter 那一幕，
而且他的陈述只有 1 条（2007 年信里那句），讨论的材料很薄。
要让「和 Buffett 讨论为什么当时用股票付」成立，需要把 1993 年信、Dexter 交易的原始披露
以及 2007 年信 Mistakes 段整节归档进材料闸。

## 结论

**骨架是教学 Agent，推演层刚起了第一根柱子。**

- 成立：真实事件 + 可溯源 + 先判断再揭晓 + 诊断→处方→复习的闭环 + 十道门禁守着不退化。
- 今天建成但未在真模型上验证：决策人复盘对话（#10）。
- 还缺：三幕的当事人材料太薄；教练层的 LLM 只有先写屏一格；「巴菲特判断」只有一幕。

## 建议的下一步（按对验收标准的贡献排）

1. **拿真 key 跑 #10 十几轮**，看出口检查的误杀率与漏杀率，调提示词。这一步不做，「LLM 扮演决策人」仍是纸面。
2. **把 Buffett 一幕的材料喂厚**：1993 年信里关于 Dexter 的段落、2007 年信 Mistakes 段全文归档并锚行号，
   陈述从 1 条扩到 5 条以上。这是「巴菲特判断」这四个字唯一的落点。
3. **教练层的 LLM 推演**：决策拍之后，让 LLM 读用户选的那个动作与他的信心，用当时可见的证据说一段
   「为什么这一步稳 / 险 / 急」（登记簿候选 #11），同样走材料闸 + 出口闸 + 标红。判分仍归规则。
4. Sunbeam 当事人是被 SEC 起诉过的真人，让 AI 替他生成新句子的风险要 owner 拍板；
   `case.json` 加 `"x_discuss": false` 即可按幕关掉。
