# 第一章 · 签字前的机器预审

> 2026-09-02。D1（19 项人工签字）之前做的一轮预审：**不是代替签字**，
> 是把 G1/G2 九条判据里机器能查的那几条接走，并把查出来的真实缺陷改掉。
> 签字仍然只能由 owner 做，剩下四条见 `python tools/sign.py --show <id>`。

## 为什么要有这一轮

签字清单第一版把九条判据全部交给人。逐条推下来发现三件事：

1. 有的判据**在数据里没有对应表示**，人拿着它也无从判断；
2. 有的判据**人一条条读根本看不出来**——它是题与题之间的分布性质；
3. 有的判据机器完全查得了，让人重做一遍是浪费他唯一不可替代的注意力。

## 查出来的缺陷（都已改）

### 1. 「红旗」还在屏上，六处 —— 门禁报的是「黑话 0 处」

owner 的第一条要求是全文去掉黑话，`check_style` 也一直报 0 处。
但它的 `SKIP_KEYS` 里有一行 `"canon"`，注释写着「正典是教材原话，不是我们的文案」。
于是正典卡（用户点得开的那张）里的 **6 个「红旗」、1 个「亮旗」、2 个「定罪」、
1 个「阳性」** 全部躲过了门禁。

两件事被混在一起了：canon.formal 确实是出处的内容，但**是我们译的、我们摘的**，
用词是我们的选择。文献里的 red flags 要引就写「原文 red flags」，
不能自己造一个中文黑话再说「这是教材的话」。

改法：`canon` 不再整体跳过（只跳 `source` 与 `x_cite` 两个纯引用标识），
十处逐一改写，`check_style` 重新数过：黑话 0 处，这次是真的 0。

### 2. 正典卡里混着我们自己的口吻 —— 六个节点

签字清单 G1-2 写着「阈值类主张标了 L3『本站口径』，没有伪装成正典」。
数据里**没有任何 L3 标记**，这条判据是悬空的。翻下来发现真实情况更直接：
六个节点的 `canon.formal` 里混着「本站教学口径…」「本节点只教…」，
而屏上那张卡的标题是「正典」，整段读起来都像出处说的。

改法：字段拆成两栏。`canon.formal` 只放出处的内容，我们自己的口径进
`canon.house`，屏上单列一栏并标明「这一段不是出处的话」。
新增门禁 **R31**：`canon.formal` 里出现「本站 / 本节点 / 我们」即报错。变异测试 3/3。

### 3. 「无法判断」这个选项，长度就是答案

90 道题里有「无法判断」选项。它是**错的**时候，72 次全都是
「信息不足，无法判断」九个字；它是**对的**时候，18 次里有 17 次
后面还跟着一句解释（「：还需要同期收入增速才能比较」这种）。

也就是说：**「后面带冒号就选它」能把这 90 道全拿下**，一点会计不用会。

每道题单看都没问题——这个线索只存在于题与题之间，人一条条审看不出来。
逐条核对那 17 句解释，发现它们的内容在 `fb`（答后反馈）里都已经写过了，
所以统一成同一句话没有损失任何教学内容。

### 4. 91% 的题，正确项是最长的那一项

同一类问题的更大版本：108 道题里 98 道（91%）的正确项是最长选项，
三选一的随机水平约 32%。「永远选最长的」能拿 91 分。

C9 挡的是位置（答案总排第一），位置能靠渲染时打乱解决，**长度不能**，它在内容里。

这一轮的处理：18 道比值 ≥2.0 的题，把正确项缩到只剩结论，推理搬进 `fb`
（`fb` 是答后才出现的，本来就是解释该在的地方）。
结果：比值 ≥2.0 的从 18 道降到 4 道，正确项最长的比例 91% → 75%。
新增门禁 **C13**：「无法判断」文案必须逐字一致（硬规则），
正确项最长的比例走棘轮只许降。剩下的差距登记为 D10。

### 5. 绝对化词偏斜 —— 查出来了，但**不改**

17 个绝对化词（一定 / 必然 / 所有 / 肯定…）里 16 个在错误项。看着像第二条线索。
但逐条看，那些词正是误解本身的形状：「肯定是造假」「只要收入还在涨」
「永远精确相等」「必然故意」。把它们软化掉，干扰项就不再代表一个
真实的错误心智模型，而 G2-1 要的恰恰是这个。

两条判据在这里冲突，服从更重要的那条。C13 对这一项**只报不挡**，
理由写在代码注释里，防止下一个人把它改成 ERROR 然后去削弱误解。

### 6. 幕可以被剧透，而没有任何东西查

一幕的全部教学价值在于「用当年拿得到的信息做判断」。任何一句
「后来 SEC 认定…」提前出现，用户就不是在判断，是在背答案——
而屏上仍然会问他「你现在怎么办」，判分照常给。

现有内容是干净的（唯一的命中是决策拍的选项标签「认定舞弊」，
那是**用户的选项**，不是剧透）。但没有任何门禁在守。
新增 **S9**：reveal 之前的叙事字段里出现结局词即报错。变异测试 3/3。

## 现在机器保证什么、人还要判断什么

| 判据 | 谁在查 |
|---|---|
| G1-1 canon 是教材的话 | R31 挡「我们的口吻」；**读起来像不像教材，人判断** |
| G1-2 阈值口径没伪装成正典 | R31 + canon.house 分栏，屏上标明 ✓ |
| G1-3 无前瞻 / 荐股 / 收益承诺 | C7 ✓ |
| G1-4 归因链一句话说得完 | **人判断** |
| G1-5 表述是当年的 | R15 时代闸 + S9 剧透闸 ✓ |
| G2-1 错误选项是真实误解 | C11 挡「没有标注」；**标得对不对，人判断** |
| G2-2「无法判断」不是惩罚项 | R22 统计占比（现 20%，目标 20–30%）✓ |
| G2-3 混淆对的 key 真能区分 | **人判断** |
| G2-4 题干不暗示答案 | C9 位置 + C13 长度与文案一致 ✓ |

**剩四条要人判断**，`sign.py --show` 会把它们单独列在最前面。

## 这一轮没做的事

- **没有代签。** 签字的意义是「有人读过并认可」，机器预审不能替代它，
  也没有写成 `x_prov` 里的任何字段——那会变成一条看起来像签字的东西。
- 两幕（buffett-1993 / lehman-2008）原有的签字已作废：审问屏此前不在
  内容指纹里（签完字之后换掉整屏证词，签字仍然有效），补进指纹后过期。
  待签从 17 项变成 19 项。

# 第二轮：多 agent 审阅（2026-09-03）

第一轮是我一个人按判据推。第二轮换了做法：**每个节点、每个混淆对、每一幕、每一道题
各派一个 agent 独立审，再派怀疑者去驳**。审的是签字清单里剩给人的那四条判据。

## 先说这一轮暴露的一个方法问题

工作流脚本里我把「活下来」写成 `survived = 核验票数 > 0 && 被驳票数 < 2`。
跑到一半会话额度打满，核验者大批失败返回 null，于是 `核验票数 = 0`——
**97 条意见被判成「没活下来」，报表上显示「被驳回 83 条」。**
实际上它们不是被驳回，是没人验过。

这正是本仓反复栽的那个坑（[[invest-coach-gate-doctrine]]），这次栽在我自己写的
汇总逻辑里：**把「验不了」当成了「验过了，不成立」**。
从 journal.jsonl 里把 97 条原样捞回来，逐条自己核。

## 捞回来之后核实的（15 条 blocker 全部成立）

四条能在归档原档里当场验的：

| 意见 | 核实 |
|---|---|
| `corroborate` 说缺口「恰好堆在应收」 | 原档 L2164 应收 −84,576，**L2165 存货 −100,810**——存货吃掉的现金更多，就印在下一行 |
| 揭晓屏「那 30 个点的增速差」 | 38.5 − 18.7 = **19.8** 个点；30 是应收增速 38.5→8.9 的**降幅**，两个量被安到了一个名字上 |
| `growth-rate`「4 千万涨 2 千万＝翻了一倍半」 | = **+50%**。教「(今年−去年)÷去年」那一关的答案面板里算错了这一课本身 |
| Dell「37→36 天（平均应收口径）」 | 平均口径算出 **35.4**（≈35）。口径标签是我们叠加的推断，原档只印了数、没写算法 |

逐字验的两条：

- **AAER 脚注 25**：这 6,200 万「includes … conditional sales, all fourth quarter bill and hold
  sales, and the sham sale of spare parts. It **does not include** instances of "pure" channel
  stuffing」。而我们的正典卡把 channel stuffing 写进了这 6,200 万的构成里，还把 conditional sales
  写成了 guaranteed sales。**这是产品里最硬的那句话，用 SEC 的口吻说了 SEC 没说的话。**
- **Asare & Wright (2004) 的 DOI**：`10.2308/aud.2004.23.2.87` 实测 **404**，这条 DOI 不存在。
  正确的是 Contemporary Accounting Research 21(2):325-352, DOI 10.1506/L20L-7FUM-FPCB-7BE2（可解析）。
  这是 canon 里唯一带页码的引证，读者按图索骥必然扑空。

还有 Sloan (1996) 的系数：卡上写 0.838 / 0.565，那是 Table 3 **Panel B**（十分位秩回归）；
全世界引用的主口径是 Panel A 的 0.855 / 0.765。卡上没写是哪个面板。

## 一个结构性毛病，不是二十个独立 bug

50 条 should-fix 里有二十条说的是同一件事：**canon.formal 把我们的教学结论用出处的口吻讲出来**，
以及 **`textbook` / `x_cite` 指向出处里不存在的结构**。

- 前者：R31 只挡得住「本站 / 本节点 / 我们」这类显式字样，挡不住
  「出处只说了 A，formal 写成『A，因此应当 B』」。十个节点各拆了一次，我们的话进 `house`。
- 后者：CFA 课纲改版后 reading 名会变（Understanding Balance Sheets → 现行已改名），
  Schilit 不同版次部次会变。处置是**不再指定版本相关的名字**，只写领域与主题——
  一个会过期的精确定位，比一个不过期的粗定位更糟。

## 顺带修掉的、面向中国读者的一个真坑

`find-filings` 屏上写「美国上市公司的年度报告叫 Form 10-K」。
在美上市的中国公司（阿里巴巴、京东、拼多多这些）报的是 **Form 20-F**。
这个节点的全部功能就是「教你去哪找」，而读者最可能去搜的恰恰是那批公司。已补上。

## 留给你裁的（我没有单方面改）

1. **`rv-ff-p1-b2` 的「无法判断」用法与同组三题相反。** a1/a2/b1 里 na 都是错的（问「够吗」，
   答案是确定的「不够」），只有 b2 是对的。审阅者说连做的用户会被精确坑掉，这个观察成立。
   但改它要动答案键，会把「无法判断」为正确答案的占比从 20% 压到 18.5%，掉出 20–30% 的目标带。
   这是产品的两条原则在互相拉扯（「承认不知道是能力」vs「用它回避是另一回事」），归 G2-2，是你的判断。
2. **两个混淆对的覆盖面**：`ts-p1` 分得开应收与收入，分不开利润表与现金流量表；
   `cf-p1` 缺了散户最容易搅混的那一刀（经营 vs 筹资），现有的一对（卖货 vs 卖厂房）难度偏低。
   补新的一对是内容增量，不是修缺陷。
3. **32 条 nit 未逐条处理**，连同若干条「归因链缺一步」的屏文案意见（需要逐屏重写而不是改一句），
   原始记录在 journal.jsonl，摘要在 scratchpad 的 d1_findings.json。

## 这一轮之后，签字面还剩什么

四条人工判据里，**G2-1（误解标得对不对）与 G2-3（key 能不能区分）已经逐条审过并修完**，
G1-1（canon 是不是教材的话）从「靠读」变成了「formal 里只剩出处的话，我们的话在 house 里单列」。
剩下真正只能由人下判断的是 **G1-4：归因链一句话说不说得完**——它要的是读者视角，不是核对。
