# 第一章 · 签字前的机器预审

> 2026-09-02。D1（19 项人工签字）之前做的一轮预审：**不是代替签字**，
> 是把 G1/G2 九条判据里机器能查的那几条接走，并把查出来的真实缺陷改掉。
> 签字仍然只能由 owner 做，剩下四条见 `python tools/sign.py --show <id>`。

## 为什么要有这一轮

签字清单第一版把九条判据全部交给人。逐条推下来发现三件事：

1. 有的判据**在数据里没有对应表示**，人拿着它也无从判断；
2. 有的判据**人一条条读根本看不出来**——它是题与题之间的分布性质；
3. 有的判据机器完全查得了，让人重做一遍是浪费他唯一不可替代的注意力。

## 查出来的缺陷（都已改）

### 1. 「红旗」还在屏上，六处 —— 门禁报的是「黑话 0 处」

owner 的第一条要求是全文去掉黑话，`check_style` 也一直报 0 处。
但它的 `SKIP_KEYS` 里有一行 `"canon"`，注释写着「正典是教材原话，不是我们的文案」。
于是正典卡（用户点得开的那张）里的 **6 个「红旗」、1 个「亮旗」、2 个「定罪」、
1 个「阳性」** 全部躲过了门禁。

两件事被混在一起了：canon.formal 确实是出处的内容，但**是我们译的、我们摘的**，
用词是我们的选择。文献里的 red flags 要引就写「原文 red flags」，
不能自己造一个中文黑话再说「这是教材的话」。

改法：`canon` 不再整体跳过（只跳 `source` 与 `x_cite` 两个纯引用标识），
十处逐一改写，`check_style` 重新数过：黑话 0 处，这次是真的 0。

### 2. 正典卡里混着我们自己的口吻 —— 六个节点

签字清单 G1-2 写着「阈值类主张标了 L3『本站口径』，没有伪装成正典」。
数据里**没有任何 L3 标记**，这条判据是悬空的。翻下来发现真实情况更直接：
六个节点的 `canon.formal` 里混着「本站教学口径…」「本节点只教…」，
而屏上那张卡的标题是「正典」，整段读起来都像出处说的。

改法：字段拆成两栏。`canon.formal` 只放出处的内容，我们自己的口径进
`canon.house`，屏上单列一栏并标明「这一段不是出处的话」。
新增门禁 **R31**：`canon.formal` 里出现「本站 / 本节点 / 我们」即报错。变异测试 3/3。

### 3. 「无法判断」这个选项，长度就是答案

90 道题里有「无法判断」选项。它是**错的**时候，72 次全都是
「信息不足，无法判断」九个字；它是**对的**时候，18 次里有 17 次
后面还跟着一句解释（「：还需要同期收入增速才能比较」这种）。

也就是说：**「后面带冒号就选它」能把这 90 道全拿下**，一点会计不用会。

每道题单看都没问题——这个线索只存在于题与题之间，人一条条审看不出来。
逐条核对那 17 句解释，发现它们的内容在 `fb`（答后反馈）里都已经写过了，
所以统一成同一句话没有损失任何教学内容。

### 4. 91% 的题，正确项是最长的那一项

同一类问题的更大版本：108 道题里 98 道（91%）的正确项是最长选项，
三选一的随机水平约 32%。「永远选最长的」能拿 91 分。

C9 挡的是位置（答案总排第一），位置能靠渲染时打乱解决，**长度不能**，它在内容里。

这一轮的处理：18 道比值 ≥2.0 的题，把正确项缩到只剩结论，推理搬进 `fb`
（`fb` 是答后才出现的，本来就是解释该在的地方）。
结果：比值 ≥2.0 的从 18 道降到 4 道，正确项最长的比例 91% → 75%。
新增门禁 **C13**：「无法判断」文案必须逐字一致（硬规则），
正确项最长的比例走棘轮只许降。剩下的差距登记为 D10。

### 5. 绝对化词偏斜 —— 查出来了，但**不改**

17 个绝对化词（一定 / 必然 / 所有 / 肯定…）里 16 个在错误项。看着像第二条线索。
但逐条看，那些词正是误解本身的形状：「肯定是造假」「只要收入还在涨」
「永远精确相等」「必然故意」。把它们软化掉，干扰项就不再代表一个
真实的错误心智模型，而 G2-1 要的恰恰是这个。

两条判据在这里冲突，服从更重要的那条。C13 对这一项**只报不挡**，
理由写在代码注释里，防止下一个人把它改成 ERROR 然后去削弱误解。

### 6. 幕可以被剧透，而没有任何东西查

一幕的全部教学价值在于「用当年拿得到的信息做判断」。任何一句
「后来 SEC 认定…」提前出现，用户就不是在判断，是在背答案——
而屏上仍然会问他「你现在怎么办」，判分照常给。

现有内容是干净的（唯一的命中是决策拍的选项标签「认定舞弊」，
那是**用户的选项**，不是剧透）。但没有任何门禁在守。
新增 **S9**：reveal 之前的叙事字段里出现结局词即报错。变异测试 3/3。

## 现在机器保证什么、人还要判断什么

| 判据 | 谁在查 |
|---|---|
| G1-1 canon 是教材的话 | R31 挡「我们的口吻」；**读起来像不像教材，人判断** |
| G1-2 阈值口径没伪装成正典 | R31 + canon.house 分栏，屏上标明 ✓ |
| G1-3 无前瞻 / 荐股 / 收益承诺 | C7 ✓ |
| G1-4 归因链一句话说得完 | **人判断** |
| G1-5 表述是当年的 | R15 时代闸 + S9 剧透闸 ✓ |
| G2-1 错误选项是真实误解 | C11 挡「没有标注」；**标得对不对，人判断** |
| G2-2「无法判断」不是惩罚项 | R22 统计占比（现 20%，目标 20–30%）✓ |
| G2-3 混淆对的 key 真能区分 | **人判断** |
| G2-4 题干不暗示答案 | C9 位置 + C13 长度与文案一致 ✓ |

**剩四条要人判断**，`sign.py --show` 会把它们单独列在最前面。

## 这一轮没做的事

- **没有代签。** 签字的意义是「有人读过并认可」，机器预审不能替代它，
  也没有写成 `x_prov` 里的任何字段——那会变成一条看起来像签字的东西。
- 两幕（buffett-1993 / lehman-2008）原有的签字已作废：审问屏此前不在
  内容指纹里（签完字之后换掉整屏证词，签字仍然有效），补进指纹后过期。
  待签从 17 项变成 19 项。
