# 开工前八问

> 每次动手前逐条回答。回答不出来的，就是还不该动手。依据：`docs/SPEC_DEV.md` §7。

1. **这次改动属于哪一层？** 内容 / 令牌 / 组件 / 管线 / 文档 —— 跨层改动要拆开提交。
2. **需要新建目录吗？已在 `docs/STRUCTURE.md` 登记了吗？**
3. **要写的每个数字，都有 fact_id 吗？** 没有就先走取数管线，不许先写文案后补出处。
4. **会改到已签字内容吗？** 改了就要重新签字（`x_prov.reviewed_hash` 会自动失效）。
5. **手机 390×844 的屏级草图画了吗？** 先画屏，再写码。
6. **新增文本达到可读性指标了吗？** meta ≥13px / UI ≥15px / 叙事正文 17–19px、行高 1.85、行长 ≤34em、正文对比度 ≥7:1。
7. **有静态兜底吗？** 后端不可达 / LLM 失败时，体验降级但不缺角。
8. **这次改动如何被机器挡住回归？** 新增哪条 validate / a11y / budget 规则。
