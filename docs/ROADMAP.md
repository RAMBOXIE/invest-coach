# 开发重心

> 这份文档只回答一个问题：**接下来该做什么，按什么顺序。**
> 依据是 [Reddit 需求调研](records/需求调研_reddit_2026-08.md)：4030 条真实帖子，
> 检索由脚本完成、解读经对抗核验，108 条证据存活。每一条结论都能在那里查到原帖。

---

## 产品是什么

**给已经在自己读财报、但读完得不出结论的散户，一套用真实历史案例训练判断力的闭卷训练。**

不教术语，只教怎么用。不给买卖建议，只训练「这家公司的数字在告诉我什么」。

---

## 一句话的重心

**内核对，包装要换，内容要补一半。**

调研支持的是机制（限量真实数字 + 只教应用 + 闭卷考核），不支持的是外壳
（游戏化叙事、反 AI 幻觉的卖点）和内容配比（全是造假案、没有干净公司）。

---

## P0：现在就做

### 1. 补负样本——最高优先级的内容缺口

现在全部内容是造假案。闭卷锚题证明的只是「你能在**已知这是造假案**的条件下答对」。
真实场景里没人告诉你这家公司值得查。这样训练出来的是**找茬偏好**，比不学更危险。

**交付物**：每一条判据配一对同构案例，其中一个是「看起来有红旗、实际没问题」的干净公司。
Dell FY1998 那个混淆对方向是对的，但它现在是高阶复训——**要变成主力题型**。

**验证**：干净公司题的占比 ≥40%；用户在「无异常」这个答案上的正确率单独统计。
如果用户倾向于在干净公司里也报红旗，就是训练出偏好了。

### 2. 加一对「热门叙事 + 估值泡沫」的案例

散户实际亏钱的地方不是精巧的会计造假，是估值和叙事。调研里最典型的一条：
有人复盘 2021 电动车崩盘，答案是 "1000 P/E ratios"——不需要任何法证会计能力就看得见。

**现有三幕（Sunbeam / Lehman / Buffett 1993）没有一幕对应用户实际踩的坑。**

**交付物**：第四幕，题材是「所有人都在讲的故事 + 撑不住的数字」。
候选：Nikola（原型车靠斜坡下滑）、Lordstown。它同时满足两件事——
是散户真踩过的坑，而且财报里**提前看得见**。

### 3. 第一幕先回答「我有什么 edge」

调研里最强的反驳不是「散户查不出造假」，是有效市场：
「你能学会读 10-K，交易对手也能」。这是用户学到第 3–5 周会自己想通、然后退出的地方。

好消息是素材已经在产品里：**Sunbeam 和 Lehman 恰好是「所有专业机构都在场却集体没看出来」**。
把它做成开场，不要埋在内容深处。

顺带要答的：为什么止损不够——红旗出现时股价通常还在涨。

### 4. 换包装

| 现在 | 改成 |
|---|---|
| Duolingo 式关卡 / streak / badge | 案例训练 / 判断复盘 |
| 主卖点「LLM 不产出事实，全部溯源」 | 主卖点「**AI 替你读，我们考你**」 |
| 入口词「识别会计红旗」 | 入口词「读财报」或「你为什么没看出来」 |

**为什么改卖点**：4030 条语料里**零条**抱怨 LLM 编数字。用户抱怨的是读 10-K 太慢
（「不如问 Claude」）。溯源不是用户已知的痛点，它是**质量背书**——
这个人群有严重的信任赤字（怕买到烂课），EDGAR accession + 行号是他们能当场验证质量的稀有信号。
所以溯源保留全部工程约束，但从主叙事退到背书位置。

**为什么改入口词**：调研里「识别会计红旗」这个词命中的人，专业 : 散户 = 1.8 : 1，
偏向 r/Accounting 和 r/FinancialCareers。散户侧的需求真实存在，但他们不用这个词搜。
被泡沫炸过的人搜的是「我做错了什么」，不是「如何识别会计红旗」。
**产品拿不到关键词流量，获客不能靠 SEO。**

### 5. 前三次会话压到 5 分钟以内

产品的认知负荷（读两页年报数字再下判断）远高于一句翻译。第一屏如果显得比看 10-K 还费劲，
当场流失。**5 分钟是硬约束，不是目标。**

## P1：紧接着做

### 6. 一个明确的、非收益的成功指标

读对了也推不出股价——公司各项健康、股票照跌，这是数学上必然会发生的。
用户会用「我学完了还是亏」判定产品无效。

**交付物**：把握度标注的**校准度**（Brier）做成首要指标，第一节课就把
「这不预测股价」钉死。否则每一轮回撤都是一次退款潮。

### 7. 免费跑完一整幕 + 退款承诺

调研里三条独立证据都指向**信任赤字而非价格敏感**：「怕买到烂课」、$5/月的 Discord 都要先问值不值。
让用户免费跑完整个 Sunbeam、看得到闭卷锚题长什么样，把「值不值」变成他自己能当场回答的问题。

### 8. 落地页三秒内答「为什么不直接问 AI」

真正的竞品不是网课，是用户手机里已有的、免费的 ChatGPT。

### 9. 与模拟盘的显式切割

「纸上练习学不到东西」这套反驳是现成的，会被原样套过来。
要说清：**不模拟交易，只模拟判断，而且判断对错有当年原档做客观裁决**——
不像模拟盘只有涨跌。

### 10. 自造外部压力结构

调研里有一条很清楚的机制：意识到能力缺口的人，在没有外部结构（考试、工作、投委会）
逼迫时会自己论证放弃。需要：公开的判断记录、有真实截止日期的锚题、同伴对照。

## 降级 / 不做

| 项 | 处置 | 理由 |
|---|---|---|
| **质问台**（逆转裁判式追问 CFO） | **不做 MVP 必需项，不做对外主叙事** | 零外部依据——没有任何一条帖子表达过对「对抗式追问管理层」的兴趣。它是最贵的设计决策。保留为单案例的故事张力素材：能传播的是「怼 CFO」这个具体场景，不是机制说明 |
| **「先判断后揭晓」写进差异化文案** | 内部机制照做，**不当卖点讲** | 零证据支持这个**顺序**有效。语料只能证明「真实材料有用」 |
| **间隔重复 / 混淆对复训作为卖点** | 机制保留，**不当卖点** | 全语料 1 条提及、0 条使用记录。机制本身有教育学依据，但没有用户需求依据 |
| **游戏化外壳** | **删除** | 在金融社区里已是负资产：有真实使用记录是「被游戏化吸引 → 因深度不够弃用 → 换回传统讲师」 |
| **B2B / 专业侧（FDD、QoE 培训）** | **只做一轮访谈验证，不转型** | 付费逻辑最硬（有截止日期、有失败代价、预设要花钱要凭证），但要另建题库（考 EBITDA 调整、净营运资本，不是 bill-and-hold），且和「面向中国散户」是两个公司 |

## 最该先花两周验证的三件事

都不用写代码。

1. **中文语料重跑**（雪球、集思录、知乎；关键词：康美、瑞幸、乐视、财务造假、看年报）。
   **这一条决定主题对不对。** 现有调研全部是英文 Reddit、美国散户——
   「识别财务造假」在英文是职业技能词，但中文语境有康美、瑞幸、乐视、中概股退市的**公共记忆**，
   很可能是大众话题。这份调研无权评判中文市场的主题选择。

2. **投一道真实的 Sunbeam 判断题，看完成率。** 不要发帖问「你会用吗」——
   调研里有人正是这么问的，拿了 0 分。**把征询变成产品本身。**

3. **找 5 个读过《Financial Shenanigans》的人，问上次实际用它抓到过什么。**
   这是「书教不会应用」这个假设最大的空白：4030 条语料里零条这样的证词。

## 目标人群

**主线**：已经在自己读财报、已经在用 AI 读、但知道自己判断力不行的自学散户。
有 3 年以上自主选股经历，会打开年报但读完得不出结论，排斥 CFA（太重）也排斥 YouTube（太散），
怕买到烂课。

**第二阶段**：被泡沫或造假炸过的人。痛最真，但**缺乏问题定义能力**——
他们的自我诊断停在「这些公司不赚钱」，不会把它和「财报里能提前看到」联系起来，
所以不会来搜你。等有了内容资产，靠案例复盘把他们从「我亏了」教育到「我缺一项可训练的技能」。

**中文市场的真正入口很可能是第三群**：被康美/乐视/中概股炸过、
且把它归因为财务造假而非运气的人。这一群在英文语料里不存在（美国散户的亏损归因是估值泡沫），
在中文可能规模很大且问题定义清晰。**这是第 1 件验证要测的东西。**

## 最可能的三种死法

写在这里是为了让每次做决定时都看得见。

1. **死于「缺口真实但不痛」。** 同一个需求形状被 5 波人跨 7 年独立提出，
   没有一条讨论超过 5 条评论，没有一条说「我在用某某」。有人把核心内容白送，0 条评论。
   反复被想到、从未被验证有人掏钱——vitamin 而非 painkiller 的典型分布。
   **表现形式：拿得到零星试用，拿不到留存和续费。**

2. **死于技能与踩坑错配。** 用户学完 Sunbeam 和 Repo 105，下一轮仍然亏在一只
   1000 倍 PE 的概念股上，然后判定产品无效。这是 P0 第 2 项要解决的。

3. **死于获客成本。** 三者叠加：通用 LLM 免费吃掉了「帮你读懂财报」；
   免费高质量 UGC（社区自产的备考大纲拿到语料里最高的教育类热度）；
   以及「整个品类不该存在」的共识——全语料最高热度的教育类观点是
   「读财经书是浪费时间」，第一条论据就是指数跑赢选股。
   **每一次公开曝光都自带一个高赞反对者，而产品的自然分发效率已被证明接近零。**
