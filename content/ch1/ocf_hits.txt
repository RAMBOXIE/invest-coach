/x_review_bank/38/quiz/opts/0/t :: 经营活动：收回主业的货款，属于做生意本身的收付

/x_review_bank/38/quiz/opts/1/t :: 不进经营活动：收入去年已经确认过，本期只是应收账款减少

/x_review_bank/38/quiz/fb :: 现金流量表按现金的来路分类，与这笔收入在哪一年确认无关。客户付货款是主业本身的收付，归经营活动；应收账款收回正是经营活动现金的主要来源之一，间接法里它就是一个正向调节项。把「收入确认年份」和「现金归类」混成一件事，是这里最常见的错法。

/x_review_bank/39/quiz/q :: 复习 · K 公司经营活动现金净流入 1.2 亿，年报披露其中 9,000 万来自把应收账款卖给第三方。你的判断？

/x_review_bank/39/quiz/opts/1/t :: 既然列在经营活动一栏，就按 1.2 亿看待

/x_review_bank/39/quiz/fb :: 经营活动这一栏最难长期造假，但仍然可以修饰。把应收账款一次性卖掉换来的现金落在经营活动一栏里，却不是主业当期收回来的钱，明年也不会自动再来一次。所以纪律是两条：看这一栏的金额，并且读清它的构成。

/x_review_bank/39/quiz/hints/2 :: 口径：看经营活动金额的同时要读它的构成

/x_review_bank/40/quiz/opts/0/t :: 这 5 亿落在投资活动一栏，经营活动那一栏并没有因此变好

/x_review_bank/40/quiz/fb :: 转让参股股权是处置对外投资，归投资活动。总现金会被这类一次性交易抬高，而经营活动那一栏不受影响，主业亏损的事实一点没变。这正是只盯经营活动那一栏的理由：它衡量的是主业自己能不能挣回现金。

/x_review_bank/41/quiz/opts/1/why :: 你把「投资活动净流入」直接等同于变卖家当。这一栏里装的不止一种东西，先问这 3 亿来自什么。

/x_review_bank/41/quiz/opts/2/t :: 能：投资活动净流入说明投资赚到了钱，是利好

/x_review_bank/41/quiz/fb :: 投资活动这一栏里可能装着卖厂房设备的钱，也可能只是到期收回的理财产品和定期存款本金，后者算不上变卖家当。它是不是坏消息，要看这笔流入的具体构成，更要看经营活动那一栏能不能自己养活主业。只看一个合计数，两个方向的结论都撑不住。

/x_review_bank/41/quiz/hints/2 :: 口径：合计数要拆开看构成，并与经营活动那一栏合起来读

/nodes/5/desc :: 现金流量表里「经营活动」那一段：主业到底收进来多少真金白银。它和净利润是两套算法算同一门生意，短期可以不同，长期应该互相靠近。

/nodes/5/canon/term :: 经营活动现金流量（Cash Flow from Operations, OCF/CFO）

/nodes/5/canon/formal :: 现金流量表将现金流分为经营、投资、筹资三类活动；处置不动产、厂房与设备等长期资产的所得列为投资活动（IAS 7）。经营活动现金净流量反映主营业务的现金创造能力，与净利润之差主要由应计项与营运资本变动构成。
